\# Pygame 2D 游戏客户端 Demo



基于 Python + Pygame 开发的 2D 游戏客户端 Demo，包含账号系统、2D 战斗、背包、掉落与 HUD。



\## 功能



\- 启动动画、登录/注册、主界面多页面切换

\- SQLite 账号数据持久化（等级、经验、生命、攻击、胜场）

\- 俯视角 2D 战斗：WASD 移动、鼠标瞄准、左键攻击

\- 4 个技能：重击、散射、回复、爆发，带冷却

\- 敌人追踪 AI、伤害数字、血条

\- 多波次刷怪、掉落物品写进数据库

\- HUD 显示等级、生命、经验、技能冷却

\- tkinter 弹窗解决 Pygame 中文输入法兼容问题



\## 操作



| 按键 | 功能 |

|------|------|

| WASD | 移动 |

| 鼠标 | 瞄准 |

| 左键 | 普通攻击 |

| 1/2/3/4 | 技能 |

| R | 战斗结束后返回主界面 |



\## 技术栈



Python、Pygame、SQLite、tkinter
